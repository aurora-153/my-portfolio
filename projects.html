ACTIVE DEPLOYMENT · 2026 CATEGORY: COGNITIVE AI SYSTEMS

SyllabusGenie Cognitive Tutor

College exam preparation often degenerates into rote cramming of lecture slides. SyllabusGenie takes university CS course syllabi (Data Structures, Discrete Math, Basic Electronics) and converts them into an adversarial, Socratic dialog agent. Using strict JSON schemas and system-prompt constraints, it refuses to simply provide the answer; instead, it guides students to formulate proofs and write bug-free code.

Sample Prompt Configuration:

{
  "system_role": "ADVERSARIAL_SOCRATIC_EXAMINER",
  "temperature": 0.15,
  "invariants": [
    "NEVER provide the direct algorithm solution in the first 3 turns",
    "FORCE the student to calculate worst-case Big-O before proceeding",
    "REQUIRE edge-case tests (NULL pointer, empty buffer, MAX_INT overflow)"
  ],
  "response_format": { "type": "json_object" }
}

C SYSTEMS LAB · 2026 CATEGORY: LOW-LEVEL SYSTEMS & GAME LOOPS

RogueTerminal ASCII Engine

A micro-game loop and procedural dungeon engine built in ANSI C99. Designed to understand cache-locality, terminal emulation escape sequences (`\033[2J`), and fixed-time physics updates without external graphics frameworks like SDL or raylib.

Arena Allocation Core:

// Zero-fragmentation contiguous arena allocator
typedef struct {
    uint8_t *buffer;
    size_t capacity;
    size_t offset;
} MemoryArena;

void *arena_alloc(MemoryArena *a, size_t size) {
    size_t aligned = (size + 7) & ~7; // 8-byte alignment
    if (a->offset + aligned > a->capacity) return NULL;
    void *ptr = &a->buffer[a->offset];
    a->offset += aligned;
    return ptr;
}
